# 隐私边界

以 [PRD §0.3](../mac/PRODUCT_REQUIREMENTS.md) 为准，这里是摘要。

**一句话**：录音在 Mac 上就转成文字、认出是谁；录音、声纹和词典从不离开这台 Mac。离开 Mac 的只有文字，以及你自己放进来的截图和文件，而且只经一条你打开、随时能撤销的 SSH 加密链路，到你自己的 DGX Spark，只用于整理。没有云端。

## 什么在哪里

| 数据 | 位置 |
|---|---|
| 原始音频、声纹 / 说话人特征、词典 | 只在 Mac 上，永不离开 |
| 逐字稿、用户放进来的文字 / 截图 / 文档、来源 App 标签、人物标识、用户的纠正决定 | Mac 上；只有用户打开链路时，才经 SSH 加密隧道发到**用户自己的** DGX Spark，只用于整理 |
| 整理结果（事件、标题、现在到哪一步、排序、提问） | Spark 生成，作为建议回到 Mac；不覆盖原始素材 |
| 手机分享的内容 | 经你自己的 SSH 密钥直接到你自己的 Spark 收件箱（不经任何第三方服务），Mac 确认取走后 Spark 删掉正文 |
| 任何数据 | 不去任何云端；没有云模型 API，没有遥测和远程崩溃上报 |

## 保证

- 链路默认关闭，由用户显式开启，随时可以撤销；关闭时立即断开并清空待发队列。收集、识别、插入和搜索都不依赖这条链路。
- Spark 端服务默认只在 0700 目录里的私有 Unix socket 上提供接口（显式设置后才另外监听 `127.0.0.1`），请求必须带链路令牌；不要把它绑定到局域网或公网。
- Mac 只把本机一个随机回环端口经 SSH 转发到这个 socket，每次请求前核对该端口的监听者是 App 自己启动的 ssh 子进程；令牌经另一条已认证的 SSH 读进内存，不落盘。Spark 主机没有默认值，用户没指定时链路不会打开。
- 收进来的内容永远只是数据：素材里的任何文字都不能触发纠正、删除或其他操作，纠正只能从界面发起；模型提示里素材放在 `<data>` 中并声明为数据。
- 开发期只发送合成数据：只有带 `SYNTHETIC_DATA_ROOT` 标记的数据目录才能发送，所有构建配置都一样；真实资料库按文件身份识别，发不出去。演示数据目录用 `-BestASRDataRoot <绝对路径>` 启动参数打开，它不能指向真实资料库或其上下级，写错时 App 直接启动失败。
- 日志不记录音频、完整逐字稿、词典内容、声纹或参与者信息。

## 仓库里有什么、没有什么

- 仓库里的评测和演示数据全部是虚构的合成数据；截图是通用聊天界面样式的合成图。
- 仓库不含模型权重、音频、真人口述、个人整理模型或评测用的私人资料。依赖私人资料的评测脚本没有公开。
- 已知的出站请求：安装模型时从 Hugging Face 按固定 revision 下载；Mac App 的自动更新检查默认关闭，只有在设置里打开后才会匿名请求本仓库的 GitHub Releases（不带用户内容）；手动检查随时可用。
