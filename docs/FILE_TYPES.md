# 能收什么：文件类型和处理位置

原则：**Mac 什么都收；图片和文件在你自己的 Spark 上读；音频只在 Mac 上处理。** Spark 收到的是逐字稿、你放进来的文字、图片副本和文件字节，只经你打开的 SSH 链路。声纹、说话人向量和词典从不发送。详细的类型清单、大小上限和评测见 [MODELS.md 的「多模态支持范围」](MODELS.md) 与 [FILE_READ.md](FILE_READ.md)。

| 输入 | 怎么进来 | 在哪处理 | 用什么 | 还不支持 / 未测 |
|---|---|---|---|---|
| 口述 | 任何 App 里按住 Fn | 只在 Mac | Qwen3-ASR（MLX）识别，插入到光标处，同时存进资料库 | — |
| 会议（线上 / 线下） | 按 App 内录系统声音，或麦克风 | 只在 Mac；Spark 只收逐字稿和分段（时间、人物 ID、你起的名字） | 识别 + FluidAudio 说话人 | 音频发往 Spark：按设计不做 |
| 会议软件导出的逐字稿 | 导入 / 拖入 | Spark | 和粘贴文字同一套规则；长会议由 item-split 切成几件事 | — |
| 导入的音视频 | 拖入 | 音轨只在 Mac；视频最多 12 张关键帧作为图片发给 Spark | 识别 + image-read | 关键帧读图质量未单独评测 |
| 图片：截图、照片、图表、幻灯片、白板、小票发票、扫描件、标签面单 | 粘贴 / 拖入 | Mac 本机读字供搜索（不发送）；另发一份缩小、不带元数据的副本到 Spark | image-read（Qwen3.6-35B-A3B NVFP4）先判类型再按类型读；98 张测试图关键字段 96.2% / 98.8% | HEIC 由 Mac 转码后再发（这条路径未在评测集上跑过）；真实照片、多图、长截图、图中的提示词注入：未测 |
| 文档和其他文件：Office（含 97–2003）、OpenDocument、PDF（含扫描件）、邮件、日程、名片、电子书、压缩包、网页存档、文本 / 代码 / 数据 | 拖入 | Spark 沙箱子进程确定性解析；扫描页和内嵌图片交给 image-read | file-read 写一句概要和票据类关键字段；Mac 另外抽出文字兜底。33 种格式、115 个测试文件：金标准答案出现在读取结果里 0.82（不含 HEIC 和视频 0.91），见 [EVALUATION.md §9](EVALUATION.md#9-读文件33-种格式) | XML 属性值没读出（0.20）、GIF 只读首帧（0.47）；真实文件评测集、.msg 真实样本：未做 |
| 粘贴的文字、聊天记录 | 粘贴 | Spark | 「名：…」行会成为人物 | — |
| 手机上分享的文字 / 链接 / 图片 | iOS 快捷指令「分享到织机」 | 先进 Spark 收件箱，Mac 取走后作为普通素材再送去整理 | 同上 | 快捷指令未在真 iPhone 上跑过（见 [PHONE.md](PHONE.md)） |

每条素材都带来源 App（粘贴取之前的前台 App，拖入取拖拽来源，手机为 iPhone）和时间，整理结果只是建议，不覆盖原件。

注意：「音频不出 Mac」指录音和按音视频导入的文件。你拖进来的其他文件（压缩包、导入列表之外的音视频格式、相机 RAW 等）不超过 25 MiB 时会原样发到 Spark，里面的音频或位置信息也一起过去（见 [PRIVACY.md](PRIVACY.md)）。
