# 收进织机（Chrome 扩展）

在 Chrome 里把**选中的文字**、**这个网页的链接**或**网页上的某个链接**收进这台 Mac 上的织机。收进来的东西和粘贴、拖入的一样，记下来源（Chrome）和时间，走同一套规则。

## 怎么装

1. 在织机里打开 **设置 → 入口 → Chrome 扩展「收进织机」** 的开关。这一下会在 Chrome 的设置文件夹里放一个很小的连接文件，告诉 Chrome：只有这个扩展可以启动织机自带的连接程序。关掉开关就删掉这个文件。
2. 在 Chrome 打开 `chrome://extensions`，打开右上角的「开发者模式」，点「加载已解压的扩展程序」，选这个文件夹（织机设置里的「在访达中显示扩展文件夹」会带你找到织机自带的那一份）。

## 怎么用

- 选中文字 → 右键 →「收进织机：选中的文字」。会带上这段文字所在网页的标题和链接。
- 在网页空白处右键 →「收进织机：这个网页的链接」；在链接上右键 →「收进织机：这个链接」。
- 点工具栏上的织机按钮：有选中的文字就收文字，没有就收这个网页的链接。

收好后，按钮上出现 ✓，网页右下角有一句提示；没收进来时出现 !，提示里写着原因（例如织机没有在运行，或者还没有在设置里打开）。

## 隐私

- **不联网。** 扩展没有任何网站权限，代码里没有任何网络请求，扩展自己的安全策略也禁止联网（`connect-src 'none'`）。
- **链接只记下，不会打开。** 织机不会去下载链接里的网页。
- **只在你点的时候读取选中的文字。** 扩展用的是 Chrome 的 `activeTab`：只有你点了菜单或按钮，它才能读当前网页的选中内容，而且只读这一次。
- 扩展不保存任何东西。东西直接交给本机正在运行的织机；织机不在运行时什么都不会收。
- 连接程序只认这个扩展（扩展的 ID 由清单里的公钥固定）；别的扩展即使知道名字，Chrome 也不会让它启动，连接程序自己也会再拒绝一次。

## Safari 和其他浏览器

Safari 不需要这个扩展：在 Safari 里点「分享」→「收进织机」（织机自带的分享扩展），或者选中文字后用 Safari 菜单 → 服务 →「收进织机」。Edge、Brave、Arc 等其他浏览器暂时没有接上，可以用 macOS 的「服务」菜单收选中的文字。
