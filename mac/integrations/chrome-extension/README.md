# 添加到 Mindloom（Chrome 扩展）

在 Chrome 中将**所选文字**、**网页链接**或**网页上的某个链接**添加到这台 Mac 上的 Mindloom。添加的内容和粘贴、拖入的一样，记录来源（Chrome）和时间，按同样的规则处理。

## 安装

1. 在 Mindloom 的“设置”>“入口”中打开“Chrome 扩展”。Mindloom 会在 Chrome 的设置文件夹中添加一个连接文件，让 Chrome 允许此扩展启动 Mindloom 自带的连接程序。关闭开关时删除该文件。
2. 在 Chrome 中打开 `chrome://extensions`，打开右上角的“开发者模式”，点按“加载已解压的扩展程序”，然后选择此文件夹（Mindloom 设置中的“在访达中显示扩展文件夹”会显示 Mindloom 自带的这一份）。

## 使用

- 选择文字后右键点按，选择“将所选文字添加到 Mindloom”。同时记录文字所在网页的标题和链接。
- 在网页空白处右键点按，选择“将网页链接添加到 Mindloom”；在链接上右键点按，选择“将链接添加到 Mindloom”。
- 点按工具栏中的“添加到 Mindloom”按钮：有所选文字时添加文字，否则添加此网页的链接。

添加后，按钮上显示 ✓，网页右下角显示一句提示；未添加时显示 !，提示中写明原因（例如 Mindloom 未在运行，或尚未在设置中打开）。

## 隐私

- 扩展没有网站权限，代码中没有网络请求，扩展的安全策略禁止连接网络（`connect-src 'none'`）。内容经 Chrome 的本机消息交给这台 Mac 上正在运行的 Mindloom。
- 链接作为文字记录。Mindloom 不下载链接指向的网页。
- 扩展使用 Chrome 的 `activeTab`：你点按菜单项或按钮时，扩展读取当前网页中所选的内容一次。
- 扩展不保存任何内容。Mindloom 未在运行时，内容不会被添加。
- 连接程序只接受此扩展（扩展的 ID 由清单中的公钥固定）：Chrome 不让其他扩展启动它，连接程序自己也会再核对一次。

## Safari 和其他浏览器

Safari 不需要此扩展：在 Safari 中点按“共享”>“Mindloom”（Mindloom 自带的共享扩展），或者选择文字后使用 Safari 菜单 >“服务”>“添加到 Mindloom”。Edge、Brave、Arc 等其他浏览器可以使用 macOS 的“服务”菜单添加所选文字。
