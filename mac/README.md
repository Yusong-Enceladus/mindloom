# Mindloom 的 Mac 客户端

这是 [织机 Mindloom](../README.md) 的 Mac 客户端源码，工程名沿用 bestASR，App 身份是 `app.mindloom`。

本机收集、语音识别、搜索与 Spark 整理链路的说明见根目录 [README](../README.md)。模块与数据流见 [架构](../docs/ARCHITECTURE.md)，合成场景的测量见 [评测](../docs/EVALUATION.md)，网络与存储边界见 [隐私](../docs/PRIVACY.md)。

源码中的 iOS、Watch、Chrome 与 Zotero 目录提供相应的实现和测试源码；协议测量见 [iOS 源码与封存协议](../docs/PHONE.md)。
