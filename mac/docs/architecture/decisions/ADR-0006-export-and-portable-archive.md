# ADR-0006：原始音频导出与可移植加密归档分离

- 状态：Accepted（架构方向；生产 KDF、口令体验与大规模流式实现待冻结）
- 日期：2026-07-23

## 决策

bestASR V1 提供两类含音频的数据出口，并与未来云同步严格分离：

1. 用户从单条历史导出音频时，整段导出保持已保留的源资产：导入媒体为原文件，本机录音为原始捕获格式。选定时间范围时生成非破坏性片段，优先保持原容器/编码；不能保持时使用无损通用格式并明确提示。
2. 完整备份/离线迁移使用版本化 `.bestasrarchive`。它包含全部可迁移历史和原始音频，以认证加密保护，并由用户设置的归档口令或恢复秘密在另一台 Mac 解锁；不能只依赖来源 Mac Keychain。
3. V1 只在 bestASR 的备份/恢复入口提供完整归档读写，不提供明文数据库、Excel 或明文目录导出。格式私有性不构成安全边界；没有正确用户秘密时内容不可读才是安全边界。
4. 云同步以后通过 `SyncAdapter` 对 records、change sets 和 assets 增量同步，不上传整个 `.bestasrarchive` 充当同步协议。

## 理由

- 单条音频导出服务于播放、分享和外部编辑，标准/原格式互操作性优先。
- 完整历史包含逐字稿、声纹、人物关系、词典和原始音频，明文数据库或表格无法满足隐私、关系完整性和可靠恢复。
- 本机 Keychain key 不能独立支持无网络、无原设备的迁移；归档必须有可移植密钥路径。
- 同步与备份的失败语义不同：同步需要增量冲突、删除和多设备状态，备份需要一致性快照、完整校验和原子恢复。

## 归档内容

包含：数据库一致性快照、原始音频、逐字稿全部修订、用户编辑、人物/声纹关系、词典、整理结果、tombstone/change log 和可迁移设置。

排除：可重新下载的模型、DerivedData、缓存、可重建索引、普通日志、诊断包、设备专属权限状态、本地主密钥和签名材料。

## 验证门槛

- 无来源 Mac Keychain 的干净测试用户可凭 archive secret 完整恢复。
- 错误口令、篡改、截断、重复文件、空间不足、未知必需字段和不支持版本在写入前失败。
- 导出与导入不产生可观察的明文数据库/音频临时目录；取消或崩溃后清理 staging 且不破坏现有库。
- 恢复后 UUID、revision、tombstone、人物操作、时间轴、原始音频 digest 和用户编辑一致；可重建索引重新生成。
- 导入是 staged + validated + atomic commit；不得部分覆盖当前历史。
- KDF、AEAD、参数、分块/压缩、口令恢复 UX 和向前迁移矩阵由 `SPIKE-MIG-001` 与 `SPIKE-SEC-001` 选择并记录。

## Spike 证据与当前边界

`SPIKE-MIG-001` 的 10 项可重复矩阵已通过，结论为 `conditional`。证据位于
`artifacts/evidence/SPIKE-MIG-001/summary.json` 与
`artifacts/evidence/SPIKE-MIG-001/matrix.json`，覆盖：

- 导入原文件和本机捕获音轨的整段字节一致导出，以及不改写源文件的 PCM16 WAV 无损区间导出；
- 使用与来源 Keychain 无关的可移植秘密，在独立临时 Keychain 身份下恢复完整快照、原始音频与稳定 UUID；
- PBKDF2-HMAC-SHA256（100,000 次）派生密钥和 AES-256-GCM 认证加密容器，以及恢复后由目标主密钥重新封装的仅密文落盘；
- 错误秘密、篡改、截断、空间预检、取消、模拟 kill、重复导入和 N-1→N 迁移。

上述 PBKDF2 参数是可执行探针参数，不是生产口令模式的最终选择。生产冻结前仍须完成内存困难 KDF 与口令/恢复秘密 UX 评估、多 GB 流式和真实磁盘满注入、真实第二 macOS 用户，以及全部发布音频容器的兼容矩阵。任何实现进入发布路径前仍须满足本 ADR 的全部验证门槛。

## 后果

- 永久保留原始音频会使归档随使用增长；导出前必须计算精确大小、检查目标空间并支持流式写入与进度/取消。
- “只有 bestASR 支持导入”是产品支持边界，不是不可逆的厂商锁定或密码学保证；用户数据安全不依赖隐藏格式。
- 后续若增加选择性归档、自动备份或云同步，必须保持完整归档可验证、可离线恢复的基线。
