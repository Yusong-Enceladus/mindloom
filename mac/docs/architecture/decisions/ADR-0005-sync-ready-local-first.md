# ADR-0005：V1 本地优先、同步可演进

- 状态：Accepted
- 日期：2026-07-22

## 决策

V1 不实现在线跨设备同步，也不要求产品账号。所有写入先提交本地库。与此同时，领域对象从第一版起使用稳定 UUID、显式 revision、tombstone、内容摘要资产引用和不可变人物操作，以便未来通过 `SyncAdapter` 接入 iPhone↔Mac 或多 Mac 同步。

## 理由

- 用户明确区分了多人音频与设备同步，并说明未来希望迁移历史或在 iPhone/Mac 同登录态同步。
- 如果第一版使用本机 rowid、绝对路径或破坏性人物合并，未来同步会迫使重写数据语义。
- 现在实现在线同步会扩大 V1 权限、账号、隐私和故障范围。

## 候选未来后端

- CloudKit private database + CKSyncEngine：适合 Apple ID 设备生态。
- 产品账号后端：适合独立登录与跨平台，但需要完整服务端、密钥和合规体系。
- 完整加密迁移包：V1 P1 已确认，既是用户备份，也可作为同步前的数据可移植性验证；具体边界见 `ADR-0006`。

## 后果

- V1 schema 和测试必须覆盖冲突友好的 ID、删除和人物操作。
- 完整离线迁移必须使用独立、可移植的加密归档；未来云同步不得通过上传整个归档包模拟。
- 音频、声纹、派生输出的未来同步默认值尚未冻结；V1 不应假装已有云端隐私承诺。
