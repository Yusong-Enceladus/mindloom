# App and model update rollback evidence

`update-rollback-summary.json` is generated by
`script/run_update_rollback_probe.sh`. It exercises ten deterministic local
fixtures with separate Ed25519 trust roots and storage namespaces for App and
model updates.

The matrix proves successful atomic activation, last-known-good retention,
signature and digest tamper rejection, interrupted staging cleanup, health-check
rollback, semantic-version downgrade rejection, and preservation of opaque user
history plus source audio. Only public-key digests are recorded. The deterministic
private keys embedded in the test executable are fixture-only and are not release
signing material.

This probe validates the update protocol boundary. It does not claim that Sparkle,
Developer ID signing, notarization, or a production update feed is integrated.
